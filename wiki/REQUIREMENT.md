# 요구사항

## 기능 요구사항

- PWA로 Obsidian 호환 Markdown vault를 탐색하고 읽을 수 있어야 한다.
- 사용자는 vault 폴더를 선택해서 열 수 있어야 한다.
- 사용자는 vault 폴더 전체를 드래그/드롭으로 열 수 있어야 한다.
- 사용자가 단일 Markdown 파일을 여는 경우, 앱은 해당 파일이 속한 폴더를 함께 열어야 한다.
- 앱은 vault의 폴더와 Markdown 파일 목록을 탐색할 수 있어야 한다.
- 앱은 파일 트리의 폴더를 기본 접힘 상태로 보여야 한다.
- 앱은 Column Browser 방식으로 폴더와 문서를 단계적으로 탐색하고 열 수 있어야 한다.
- 앱은 Markdown 문서를 읽기 화면에 렌더링해야 한다.
- 앱은 프리뷰에 표시된 임베드를 접고 펼칠 수 있어야 한다.
- 앱은 Obsidian 내부 링크(`[[문서]]`)를 열 수 있어야 한다.
- 앱은 기존 Markdown 링크(`[라벨](경로)`)를 열 수 있어야 한다.
- 앱은 문서 간 링크 관계를 Graph View로 볼 수 있어야 한다.
- 앱은 최근에 열람한 문서 또는 마지막 탐색 상태를 다시 열 수 있어야 한다.

## 비기능 요구사항

- vault의 원본 파일명, 폴더 구조, Markdown 원문을 변경하지 않아야 한다.
- 초기 범위는 읽기 전용으로 유지한다.
- 데스크톱과 모바일에서 PWA로 사용할 수 있어야 한다.
- 문서 읽기 화면은 가독성을 우선해야 한다.
- 다양한 테마를 지원할 수 있도록 스타일 변수 기반으로 UI를 구성해야 한다.
- 기본적인 오프라인 재열람 또는 캐시 동작을 지원해야 한다.
